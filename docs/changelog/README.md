# Change records

This directory is the running explanation of how the project changes over
time. Git records the exact diff; these entries record the design and research
reasoning around it.

Every coherent change adds or updates a file named
`YYYY-MM-DD-short-description.md`. Several related edits may share an entry,
but unrelated work should not be bundled merely because it happened on the
same day.

## Required sections

1. **Summary** — what changed.
2. **Reason** — why it changed now.
3. **Dynamic SPD comparison** — what the reference implementation does, with
   paths relative to `/home/phroz/spd/dynamic_social_democracy`, and what this
   project retains, adapts, or rejects.
4. **System fit** — effects on upstream and downstream systems.
5. **Research and assets** — source, claim-level citation, and rights impact,
   or an explicit statement that there is none.
6. **Validation** — tests, builds, inspection, or unresolved checks.

Use [the template](TEMPLATE.md) for new entries. An entry documents a decision;
it does not replace a detailed implementation plan, event research record,
bibliography entry, or asset-rights record.
