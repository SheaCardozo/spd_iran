# v0.3 Dynamic convergence adversarial review

## Scope

This review compares the compiled Iran campaign with Dynamic SPD's hand,
discard, reducer, adviser, recurring-card, election, event, status, and
Library responsibilities. It also applies the project-wide scene standard to
all **216 compiled scenes**.

## Findings

The automated classification covers 216/216 scenes with zero failures. The
opening remains pre-formation opposition work: it does not leak the National
Front into January 1949. Every recurring card has a developed setup,
historical/flavour-led choice subtitles, visible consequence prose, and a
universal return route. Internal routing and roster toggle scenes are
classified separately so framework mechanics are not mistaken for narrative
decisions.

The main convergence defects identified in v0.2 are resolved:

- the Dynamic-mode hand contains four cards and cancellation restores the
  original agenda rather than redrawing;
- no more than three eligible advisers are active once the pool grows, and
  roster work is distinct from consultation work;
- faction condition, support, resources, Crown pressure, projects, and place
  records all have downstream consumers;
- election work can affect a return only at a sourced contestable place;
  credential work cannot create a return;
- nationalization support is derived separately for usable Majles and Senate
  records and can produce either chamber-defeat ending; and
- prior decisions receive conditional prose callbacks and can cause minor
  coalition or Crown reactions.

## Remaining boundary

The exact counterfactual chamber division is a game rule, not a historical
reconstruction. The prose and research record say so, and no historical
evidence field receives the simulated oil position. Khalil Maleki remains
ineligible before the endpoint because the current authoritative record does
not justify an earlier adviser entry. This is an evidence constraint rather
than missing roster functionality.

No new art was introduced. The full primer remains available from the main
menu, while the in-run chronology reveals only seen/current anchors.
